# 数据卡：auction-moment-public-v1

## 范围

- 观察日期：2026-07-27 至 2026-08-02。
- 原始场次：1,816；其中 1,794 场有可用终局藏品表。
- 档位：当前公开样本均为 S 档。
- 数据形态：UTF-8 CSV、JSON 与 JSONL；不含任何图片或二进制证据。

## 来源与处理

数据来自私有采集工程生成的结构化场次、终局结算、事件和对手轮次表。公开导出
过程只读取这些派生文本表，不复制图片、网络包或第三方程序文件。

隐私处理包括：

1. 会话 ID 通过带未公开密钥的 HMAC-SHA256 替换；
2. 玩家昵称和已有玩家键再次使用独立命名空间重新加密；
3. 删除自身昵称、原始 ID、精确时间、本机绝对路径和源文件路径；
4. 对手时间只保留日期，以维持时间外验证；
5. 删除输入动作和 UI 状态遥测，它们不属于公开研究问题。

密钥不随仓库发布，因此公开伪 ID不能被用于恢复原始值，也不承诺跨数据版本稳定。

## 时间与因果边界

`settlement_total`、终局藏品、最终数量、对手本轮最终报价和最终排名都属于
结果时间信息。它们可以用作标签、赛后描述或下一轮已知历史，但不得进入同轮
出价前特征。

## 已知限制

- 数据覆盖一个短时间窗口和单一档位，不能代表游戏的完整事件池或长期分布。
- 文本表可复现当前统计与表格模型，但无法复现视觉模型训练。
- 玩家伪 ID 仅用于同一公开版本内的重复观察研究，不能解释为真实身份。
- 分析结论仍需新的未消费时间块做前瞻复验。

## 完整性

[`manifest.json`](manifest.json) 保存每个公开文件的行数、字节数和 SHA-256。
运行 `python scripts/verify_public_release.py` 可检查哈希、禁止扩展名、绝对路径和
未匿名化会话 ID。
