# 中间态视觉模型卡

本模型包供无持久化实时研究助手识别竞拍过程中的可见信息。它不包含抓包、
协议解析、原始截图、玩家身份、会话记录或最终结算数据。

## 模型组成

| 文件 | 任务 | 类别 |
|---|---|---:|
| `clue-spatial-yolo26n-v1.pt` | 左上角、完整轮廓、完整揭示的空间检测 | 3 |
| `clue-detector-yolo26n-v1.pt` | 空间状态与品质属性检测 | 13 |
| `treasure-classifier-yolo26n-v1.pt` | 完整揭示藏品的目录身份分类 | 120 |
| `world-model-v1-S.json` | S 档完整藏品池的分层概率先验 | 120 个目录身份 |

三份 `.pt` 使用 Ultralytics 训练和加载，模型资产及与其组合的助手运行代码按
AGPL-3.0 发布。世界模型 JSON 由本仓库 Apache-2.0 代码和 CC BY 4.0 数据
再生。若使用者持有适用的 Ultralytics Enterprise License，应自行依据其授权
条款判断使用范围。本模型卡不是法律意见。

## 输入与输出

- 输入是 `1280×720` 横屏游戏画面的内存截图。
- 地图区域会归一化为 `600×600`、10 列网格视口。
- 空间和属性检测输出网格锚点、可见规格与品质候选。
- 身份分类只对完整揭示框运行，并输出目录 ID Top-k。
- RapidOCR 负责轮次、公共/个人事件和持有金额，不属于本模型包的自训练权重。

## 已知限制

- 当前冻结逐轮评估仍标记为 `needs_gold_review`：部分验证场次的人工金标不满足
  跨轮单调性，不能把干净子集指标冒充全量生产结论。
- 自动检测可能漏掉新增位置/品质揭示，也可能保留误检；助手必须提供人工补充、
  删除和修改入口。
- Top-k 概率是分类器分数，不是完整世界后验概率。
- 世界模型与实时推理返回的区间尚未证明具有校准覆盖率，只能作为研究估计。
- 模型只针对当前游戏版本、S 档和 `1280×720` 布局验证；其他版本或分辨率应
  默认视为不兼容。

## 发布净化

Release 构建器会删除 PyTorch 检查点中的训练目录、Git 根目录、优化器和缩放器
状态，重新加载后验证所有参数张量哈希保持一致，并拒绝包含 Windows 绝对路径
或原始时间戳式会话 ID 的产物。最终文件身份以 Release 中的
`model-manifest.json` 和 `SHA256SUMS` 为准。

## 隐私与数据边界

模型包不包含训练图片。运行时画面、OCR 结果、人工修正和预测只保存在本局
内存，不写入日志、缓存或会话目录；静态模型文件本身会保存在用户指定的模型
目录。终局和退出会清空本局状态。
